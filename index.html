The Demo Concierge

Never lose a warm lead to slow follow-up. Triage every demo interaction within 10 minutes.

The Problem

2,346 cold emails. 1 reply. 0 follow-up.

AI Agents gets 50+ demo requests per month from serious prospects: plumbers, electricians, HVAC contractors, dentists. They watch the demo, they're interested, and then... nothing.

The warmest 1% of your inbound funnel goes cold within 24 hours.

Why? Because follow-up is treated as broadcast, not triage. You send everyone the same generic message and hope something sticks.

The Insight

The money isn't in the demo. It's in the 10 minutes after.

When a prospect finishes watching, they have one question in their head: "Is this worth pursuing or too complex?"

In that 10-minute window, the right follow-up converts at 3–5x the rate of spray-and-pray.

Not by convincing harder. By reading the signal and meeting them where they actually are.

The Solution

The Demo Concierge is a disciplined follow-up operator that owns those critical 10 minutes.

Five decision paths. One mandatory rule. Vertical-specific templates. Bilingual routing.

Every demo interaction gets the right next step. Not guessed. Not assumed. Read.

The 5 Decision Paths

🔥 Path 1: Hot Lead

Demo completed + booking requested

Send: Booking confirmation (immediate)

Confidence: 95%

❓ Path 2: Abandoned

Demo exited midway

Send: Clarification ("What broke?")

Confidence: 65%

🌡️ Path 3: Lukewarm

Demo completed, no booking

Send: 3-day nurture sequence

Confidence: 65%

⭐ Path 4: Repeat Visitor

Viewed 2+ times in 7 days

Send: Escalate to human (high intent)

Confidence: 95%

🚫 Path 5: Competitor

Research-only signal or competitor domain

Send: Polite close (no follow-up)

Confidence: 95%
Rule 0 — The Moat:
No complete event data = no outreach. Ever. This prevents spray-and-pray and signals discipline.

Key Features

⏱️

10-Minute SLA

Hot leads get a message within 10 minutes. Lukewarm leads trigger nurture within 30 min. Cold leads are archived.

🌍

Bilingual Native

Spanish-speaking prospects get actual Spanish templates, not translations. Vertical-native tone, not generic pablum.

✅

Vertical Specific

Plumber, electrician, HVAC, dentist — each gets messaging that respects their business model and pain points.

🔄

Explicit Routing

Every outcome gets a back_to field: null (done), escalate-human (rep takes over), or nurture-sequence (auto drip).

📊

Confidence Scoring

Each classification comes with confidence (95% = booked call, 65% = abandoned). You know what's reliable.

🛑

Rule 0 Discipline

Incomplete event data? Return error. Don't guess. Don't send to ghosts. This is the moat.

How It Works: Timeline

0 min
Demo ends. Event data arrives (prospect name, email, vertical, outcome)
1–2 min
Rule 0 check: Is event data complete? If no → error return. If yes → proceed.
3–10 min
Classify path (1–5) based on demo outcome signal. Select matching template (vertical + language). Send message.
10 min+
Record outcome with confidence score. Route via back_to field (null / escalate / nurture).
60 min (if Path 2)
If no response to clarification → escalate to human. Human follows up.
3 days (if Path 3)
Lukewarm lead receives 3 nurture emails (Day 1: recap, Day 2: case study, Day 3: team call).

What Makes This Different

vs. Spray-and-Pray: Generic systems send the same email to everyone. The Concierge reads the signal first.

vs. No Follow-Up: Many teams don't follow up at all (too afraid of spam complaints). The Concierge has discipline. Incomplete data = no outreach. That's the moat.

vs. English-Only: Most systems translate English templates to Spanish. The Concierge uses native Spanish messaging. There's a difference.

vs. Automation Overkill: The Concierge isn't a bot that never escalates. Hot leads and repeat visitors go straight to human (via back_to field). Automation supports humans; it doesn't replace judgment.
